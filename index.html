Mentor de Carreiras com Inteligência Artificial

Projeto prático desenvolvido com Python, API do Google Gemini, System Prompts, GuardRails e boas práticas de segurança de chaves.

1. IA no Colab

Integração do SDK oficial google-genai em ambiente Google Colab para gerar respostas inteligentes.

2. Segurança de API

Proteção da GEMINI_API_KEY utilizando o gerenciador de segredos (Userdata) do Colab sem expor dados no código.

3. System Prompt & GuardRails

Definição de persona profissional e regras rígidas para manter o foco exclusivo em orientação de carreira.

4. Controle de Tokens

Limitação de max_output_tokens e histórico enxuto para otimizar custos e consumo de processamento.
